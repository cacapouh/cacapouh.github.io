KiriSub Privacy Policy

Last updated: 2026-10-07

KiriSub is a personal tool operated by and for the owner of a single YouTube channel. It uses Google OAuth to access that owner's own YouTube account in order to upload videos, set captions and thumbnails, and read YouTube Analytics for the channel.

  • Data accessed: the owner's YouTube channel data and YouTube Analytics data, through the YouTube Data API and YouTube Analytics API.
  • Use: only to manage and analyze the owner's own channel.
  • Storage: OAuth tokens and reports are stored only on the owner's own computer.
  • Sharing: no data is sold, shared with, or transferred to third parties.
  • Other users: the tool is not offered to anyone else.

KiriSub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

To revoke access, visit Google Account permissions.
